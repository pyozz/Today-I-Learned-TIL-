# 리액트 컴포넌트

컴포넌트란 UI를 구성하는 **독립적이고 재사용 가능한** 단위입니다.

하나의 웹 페이지를 개발할 때 모든 코드를 한곳에 작성하는 것이 아니라, UI의 **역할과 기능에 따라** 여러 개의 컴포넌트로 분리하여 개발하는 방식입니다.

예를 들어 하나의 웹 페이지를 다음과 같이 구성할 수 있습니다.

- Header: 웹 페이지의 상단 영역
- Main: 주요 콘텐츠 영역
- Footer: 웹 페이지의 하단 영역

이처럼 하나의 페이지를 여러 컴포넌트로 나누어 개발하면 각각의 역할이 명확해지고, 독립적으로 관리할 수 있습니다.

## 컴포넌트를 사용하는 이유

컴포넌트를 사용하는 가장 큰 이유는 **재사용성**과 **유지보수성**입니다.

- 재사용성<br />
  동일한 UI나 기능을 여러 곳에서 재사용할 수 있습니다.

  예를 들어 여러 페이지에서 동일한 버튼이 필요하다면 버튼 컴포넌트를 한 번 만들어 두고 필요한 곳에서 사용할 수 있습니다.

  이렇게 하면 동일한 코드를 반복해서 작성할 필요가 없으며, 코드의 중복성을 줄일 수 있습니다.

- 유지보수성<br />
  컴포넌트별로 역할과 책임이 분리되어 있기 때문에 특정 UI에 수정이 필요한 경우 해당 컴포넌트만 수정하면 됩니다.

  모든 코드가 한곳에 모여 있다면 수정해야 할 부분을 찾기 어렵고 다른 기능에 영향을 줄 가능성도 있습니다.

  반면 컴포넌트 단위로 분리하면 코드의 구조가 명확해지고 수정 및 관리가 쉬워집니다.

<br />

- 컴포넌트 사용 예시

```javascript
function Header() {
  return <header>Header 영역</header>;
}

function Main() {
  return <main>Main 영역</main>;
}

function Footer() {
  return <footer>Footer 영역</footer>;
}

function App() {
  return (
    <>
      <Header />
      <Main />
      <Footer />
    </>
  );
}

export default App;
```

위 예시에서는 Header, Main, Footer를 각각 독립적인 컴포넌트로 분리했습니다.

App 컴포넌트에서는 이들을 조합하여 하나의 웹 페이지를 구성합니다

<br />

> 컴포넌트는 단순히 코드를 여러 파일로 나누는 것이 아니라, UI의 역할과 책임에 따라 독립적인 단위로 분리하는 것입니다.
