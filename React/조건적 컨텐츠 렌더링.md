React에서는 State나 Props의 값에 따라 **화면에 보여줄 콘텐츠를 동적으로 변경할 수 있습니다.**

대표적으로 다음과 같은 방법이 있습니다.

- 삼항 연산자 ? :
- 논리 연산자 &&
- 변수에 JSX를 저장한 후 렌더링

<br />

### 삼항 연산자를 이용한 조건부 렌더링

JSX에서는 다음과 같이 사용할 수 있습니다.

```javascript
{
  isSelected ? <p>선택되었습니다.</p> : <p>한 가지를 선택해주세요.</p>;
}
```

<br />

### 논리 연산자 &&를 이용한 조건부 렌더링

두 번째 방법은 논리 연산자인 &&를 사용하는 것입니다.

```javascript
{
  isSelected && <p>선택되었습니다.</p>;
}
{
  !isSelected && <p>한 가지를 선택해주세요.</p>;
}
```

삼항 연산자와의 차이는

```javascript
// 삼항 연산자
true  → A
false → B

// 논리 연산자
true  → A
false → 아무것도 표시하지 않음
```

삼항 연산자는 둘 중 하나를 반드시 선택하는 반면,<br />
논리 연산자는 조건이 참일 때만 보여준다는 차이가 있습니다.

<br />

### 변수를 이용해서 동적으로 렌더링하기

세 번째 방법은 **렌더링할 JSX를 변수에 저장한 다음 사용하는 방법**입니다.

변수를 이용한 방식은 **JSX 안에서 조건을 처리하는 것이 아니라, JSX를 반환하기 전에 JavaScript에서 어떤 콘텐츠를 보여줄지 결정하는 방식**입니다.

```javascript
let tabContent = <p>한 가지를 선택해주세요.</p>;

if (selectedTopic) {
tabContent = (
  <div id="tab-content">
    <h3>{topic}</h3>

    <p>{description}</p>

    <pre>
      <code>{code}</code>
    </pre>
  </div>
);

return (
	{tabContent}
)
```
